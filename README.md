# E-Commerce-Data-Analytics

E-Commerce Data Analytics Project
Project Overview

This project analyzes E-Commerce sales, customers, products, orders, and payments to generate meaningful business insights.

The project follows an end-to-end Data Analytics workflow using Python, PostgreSQL, SQL, and Power BI.

🛠️ Tools & Technologies
Python
Pandas
NumPy
Matplotlib
Seaborn
PostgreSQL
SQL
Power BI
🔄 Project Workflow

Data Loading → EDA → Data Cleaning → PostgreSQL → SQL Analysis → Power BI Dashboard → Business Insights

 Python

Python was used for:

Loading datasets
Data understanding
Exploratory Data Analysis
Missing-value analysis
Duplicate detection
Data cleaning
Data visualization



🗄️ PostgreSQL & SQL

Cleaned data was loaded into PostgreSQL.

SQL analysis was performed to find:

Total Revenue
Total Orders
Top Customers
Top Products
Revenue by Category
Revenue by State
Payment Analysis
Order Status
Monthly Revenue

An interactive dashboard was created to analyze:

Revenue
Orders
Customers
Products
Monthly Revenue
Revenue by State
Revenue by Category
Top 10 Customers
Top 10 Products
Payment Types
Order Status

Interactive slicers were added for Year, State, Category, Payment Type, and Order Status.
